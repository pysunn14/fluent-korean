# fluent-korean: 코덱스용 한국어 스킬

코덱스가 의미가 명확하고 비교적 자연스러운 한국어 문장을 작성하도록 안내하는 스킬입니다. 수려한 문체보다는 의미를 정확하게 전달하는 데 초점을 맞춥니다.

이 저장소는 [snflkd/fluent-korean](https://github.com/snflkd/fluent-korean)을 코덱스 스킬 형식으로 옮긴 공개 포크입니다. 한국어 작성 지침과 미트 사용권은 원본을 따르며, 코덱스용 포장 구조와 설치 안내만 바꾸었습니다.

한국어로 요청하거나 작업 결과물에 한국어가 포함될 때 특히 유용합니다. 코드, 코드 주석, 외국어 문장, 프로젝트에서 이미 정한 문체는 임의로 한국어 문체로 바꾸지 않습니다.

## 왜 필요한가

코딩 에이전트는 답변을 짧게 만들면서 조사와 어미를 생략하거나, 명사만 이어 붙이거나, 의미가 맞지 않는 비유적 표현을 사용할 때가 있습니다. 이런 문장은 읽는 사람이 뜻을 복원해야 하므로 소통 비용이 커지고, 한국어 산출물의 완성도도 낮아질 수 있습니다.

fluent-korean은 다음 원칙을 통해 이런 문제를 줄입니다.

1. 필요한 문장 성분과 조사, 어미를 생략하지 않습니다.
2. 명사구만 나열하기보다 서술어와 종결어미가 있는 문장을 사용합니다.
3. 비유적인 어휘보다 뜻이 분명하고 실제로 통용되는 어휘를 우선합니다.
4. 외국어와 코드에까지 한국어 지침을 억지로 적용하지 않습니다.

## 설치

### 코덱스에서 설치를 맡기는 방법

코덱스에 다음과 같이 요청합니다.

```text
$skill-installer를 사용해서 https://github.com/pysunn14/fluent-korean 저장소의 루트 스킬을 fluent-korean 이름으로 설치해줘.
```

설치한 다음 대화에서 자동으로 사용할 수 있습니다. 스킬이 목록에 나타나지 않으면 코덱스를 다시 시작합니다.

### 직접 설치하는 방법

개인 스킬 폴더에 저장소를 복제합니다.

```bash
git clone https://github.com/pysunn14/fluent-korean.git ~/.agents/skills/fluent-korean
```

코덱스는 `~/.agents/skills/fluent-korean/SKILL.md`를 개인 스킬로 찾습니다. 저장소 안에서만 사용하려면 해당 저장소의 `.agents/skills/fluent-korean` 위치에 복제해도 됩니다.

## 사용

한국어 답변이 필요한 요청에서는 스킬 설명에 따라 자동으로 선택될 수 있습니다. 직접 지정하려면 요청에 다음 이름을 포함합니다.

```text
$fluent-korean
```

## 세부 동작 조정

원하는 조항을 골라 `SKILL.md`의 끝에 추가할 수 있습니다.

### 초보 개발자에게 맞추기

```text
- 코딩에 관해서는 초보 개발자가 이해할 수 있도록 서술하고, 현장감이 과한 구어체 표현은 더욱 자제합니다. 예를 들어 박아넣다, 치우다, 얹다 같은 표현을 피합니다.
```

### 높임말을 엄격하게 사용하기

```text
- 사용자를 사용자님이라고 호칭하고, 선어말어미와 어말어미, 조사, 공손어휘를 통해 사용자께 높임말을 사용합니다. 사용자에게 반말이나 비존대로 발화하지 않습니다.
```

### 통용되지 않는 어휘 줄이기

```text
- 한국어 사전에 있는 어휘이며 뜻이 명확하더라도, 사용 빈도가 낮아서 통용되지 않는 어휘를 사용하면 소통의 효율성이 오히려 낮아지니 자제합니다. 대신 의미가 명확하며 실제로 통용되는 어휘를 우선적으로 선택합니다.
```

### 모든 한국어 산출물에 적용하기

```text
- 한국어로 출력되는 모든 결과물에도 이 지침들을 적용합니다.
```

### 별도 문체가 있는 작업은 제외하기

```text
- 구체적인 지침이 따로 존재하는 산출물 유형에는 이 지침을 적용하지 않습니다. 적용 여부가 애매하다면 사용자에게 확인합니다.
```

### 출력 전에 점검하기

```text
- 답변을 사용자에게 출력하기 직전에, 위의 지침들에 어긋난 부분을 반드시 점검하고 수정한 후에 출력합니다.
```

## 범위와 유의점

- 문장 성분을 복원하고 지침을 불러오므로 토큰을 조금 더 사용할 수 있습니다.
- 이 스킬은 의미가 명확한 한국어를 미리 유도합니다. 번역체 교정, 맞춤법 검사, 사람처럼 보이게 만드는 후처리 도구와 목적이 다릅니다.
- 하위 에이전트가 별도 환경에서 실행되면 스킬 적용 여부가 달라질 수 있으므로, 한국어 품질이 중요한 작업에서는 결과를 확인합니다.
- 원문의 작성 배경과 자세한 설명은 [원본 저장소](https://github.com/snflkd/fluent-korean)에서 확인할 수 있습니다.
